# GosdumaMusic (Django)

Проект реализован на **Python Django** и предназначен для запуска в PyCharm.

## Функционал
- Регистрация пользователя (уникальные логин/e-mail, ФИО кириллицей, телефон `8(XXX)XXX-XX-XX`).
- Авторизация пользователя.
- Личный кабинет с профилем и списком заявок.
- Сообщение при отсутствии заявок и переход к созданию новой.
- Создание музыкальной заявки со статусом `Новая`.
- Панель администратора (логин `BraveGuap`, пароль `gosdum`) с изменением статусов заявок.

## Запуск
1. Создайте виртуальное окружение.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Примените миграции:
   ```bash
   python manage.py migrate
   ```
4. Запустите сервер:
   ```bash
   python manage.py runserver
   ```

## Структура
- `gosdumamusic/` — настройки и маршрутизация проекта.
- `portal/` — приложение с моделями, формами, страницами и стилями.
